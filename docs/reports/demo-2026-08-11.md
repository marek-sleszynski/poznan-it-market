## Reproduce

From the project root, after the setup in the [README](../../README.md):

```bash
make demo
uv run --locked python scripts/check_results.py --mode demo
```

The checker reads the local demo database, compares raw data with the sample and verifies
the results of the shared queries in `sql/analysis/`.

## Limits and updates

This is a small, saved example from one source. It does not describe the current market,
a time trend or whether the offers are still active.

This report and the README images are updated manually. Live charts are available in the
